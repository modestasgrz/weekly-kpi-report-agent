# weekly-kpi-report-agent

Weekly sales KPI report where every number is computed in code, the LLM only writes the narrative around the given figures, and a checker rejects any number in the text that is not in the computed set.

Status: in development.

## Data

Uses the public **Online Retail II** dataset: Chen, D. (2012). Online Retail II [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D — licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The raw file is downloaded by a script and is not committed.
